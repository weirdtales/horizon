## Current Alignment

- Product goal: one polished, self-hosted dashboard for homelab service visibility and common operations.
- Technical direction: keep credentials server-side, use local API routes for integrations, generate the module registry from `modules/*`, and persist settings in `data/settings.json`.
- Near-term focus: make real service wiring consistent, close plugin upload/delete auth mismatch, and align settings/module types.
